# 市场事件归因系统

首页是事件归因工作台：对 2026 年 7 月每一个严格超过 2%、3% 或 5% 的日度异动（涨跌分别统计，共 66,128 个股票日），给出市场、行业与个股特有的收益分解，以及按样本校准的原因概率。证据来自同期全市场公告元数据、财经文章元数据和成交盘口指标；没有公开信息的事件归于成交与盘口本身。数据覆盖 **2026-07-01 至 2026-07-31，5,210 个股票代码、23 个日期、119,652 个股日**。

[进入事件归因工作台](./index.html) · [归因方法](./docs/ATTRIBUTION_METHOD.md) · [历史事件证据页](./evidence.html) · [研究口径](./docs/REAL_DATA_METHOD.md) · [保留的盘中 Demo](./demo.html)

## 事件归因

- 收益分解：个股收益 = 同日样本中位数（市场） + 同行业中位数减市场（行业） + 个股特有部分；行业来自公告元数据的申万一级标签。
- 证据窗口：前一交易日收盘后至当日开盘前、当日交易时段、当日收盘后（只作事后解释）、此前 2 至 5 个交易日。样本内 99% 以上的公告在收盘后发布。
- 概率：对每种证据统计异动日与非异动日出现频率之比，取 1 − 1/似然比 为可归因份额并按比例分配个股特有部分；似然比低于 1.5 的证据只列出不计入；成交盘口证据始终保留最低权重。
- 资金流向：供应商日资金流向拆分（小、中、大、超大单；主力 = 大单 + 超大单）提供主力与超大单净流出或净流入、散户接盘等特征，并在事件页面列出各档净流入金额与占成交额比例。
- 边界：全部数字是样本内经验关联，不是因果证明；公告与文章只展示标题、时间与来源链接，原始记录、凭证和供应商批量数据不进入本站。

数据文件：`data/attribution/index.json`（元数据、校准表、股票字典）与 `data/attribution/events/YYYYMMDD.json`（按日期分片的事件、原因与证据）。构建程序为 `tools/build_attribution.py`，输入为本地日汇总与私有证据目录，详见归因方法文档。

## 数据接入与凭证

`sources.html` 列出本站的每条数据路线（公告搜索、公众号文章搜索、个股资金流向、日行情连接检查、S3 文件服务、MCP 网关、本地快照档案）的用途、鉴权方式、计费口径、覆盖范围和最近一次连接检查的脱敏结果，由 `tools/build_sources.py` 生成 `data/sources.json`。凭证只存放在 GitHub 仓库 Secret（`DATAYES_API_TOKEN`、`DATAYES_S3_TOKEN`）和本地构建环境的忽略目录中；页面提供“在 GitHub 更换 Token”和“运行连接检查”入口，工作流 `Data sources check`（`tools/check_data_sources.py`）对每条路线各发一次请求并只保留状态类别。静态页面不保存也不读取密钥。

## 历史事件证据页

`evidence.html` 保留此前的日度证据工作台：严格下跌超过 5% 的事件、同期样本比较、历史成交量和流动性基准。

## 研究范围

页面支持按日期、股票和数据质量筛选事件，查看截至事件日期的价格路径、同期样本收益比较、仅由此前观测计算的成交量和价差基准，以及可追溯的证据导出。当天完整汇总属于日终信息，不能作为盘中已知信息。

源数据的最后快照价格和参考前收盘用于计算收益代理，尚未由官方收盘、复权和公司行动数据独立核验。同期样本中位数不是官方市场指数，收益差不是因果贡献。页面不生成原因概率，也未接入新闻、公告或历史行业证据。质量标记和历史不足会在事件中明确显示。

用户已授权先以现有本地数据完成这一版本。最近一年的全部 A 股是后续补充数据目标，当前页面不宣称已经覆盖该范围。新供应商有限导出的行情日期位于 2025 年，且证券与行业连接不完整，因此没有并入本研究或发布到本仓库。

## 盘中回放（真实证据）

`demo.html` 回放八只股票、23 个交易日、8,832 根五分钟 K 线，按原有阈值规则在盘中触发事件。每个事件弹窗给出该股票日的日终归因原因与概率（与首页同一套方法；日终涨跌幅未超过 2% 的交易日不给概率），并列出本公司公告、直接提及本股的财经文章、行业报道与宏观政策背景，附发布时间和来源链接，按事件时点区分"事件前已知"和"事后披露"；盘口变化取自五分钟 K 线与日终汇总。证据包为 `data/replay_evidence.json`，由 `tools/build_replay_evidence.py` 生成，不含正文。阈值规则见 [回放方法](./docs/METHOD.md)。

## 数据与复现

`data/study.json` 是日度事件、同日样本统计和数据来源清单；`data/series/` 提供按代码前缀划分的历史指标。完整原始快照、私有 Parquet、账户和供应商批量导出不进入本站。研究构建程序为 `tools/build_real_study.py`，具体计算、筛选及复现参数见研究口径文档。

页面为静态站点，使用相对路径部署于 GitHub Pages，不依赖运行中的云端实例。

官方 API 接入正在准备，当前没有完成带有效令牌的业务调用，首页仍为上述本地历史数据。[连接配置说明](./docs/DATAYES_CONNECTION.md)列出供应商需确认的权限、Secret 配置和手动小范围检查。`DataYes connection check` 工作流只有手动触发，单次最多查询一个股票日；通过一次检查也不等于取得全年全市场或完成网站数据源替换。

```sh
python -m http.server 8080
npm test
python -m unittest discover -s tests -p 'test_*.py'
python tools/check_attribution_browser.py
python tools/check_real_browser.py
python tools/check_browser.py
python tools/validate.py
```

浏览器检查覆盖本地子路径和公开 HTTPS、筛选与导出、历史信息边界及移动端。通过检查后，`tools/publish.py` 只发布经过检查的文件到已有目标仓库。
