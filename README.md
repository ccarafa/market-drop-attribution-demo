# 股价下跌归因演示

面向八只股票的公开历史回放网站。当观察到股价跌幅严格超过 5% 时，界面弹出三个候选解释，并按照预设的示例概率从高到低排列。

**价格来自历史数据；原因和概率均为虚构演示内容。** 例如“财报低于预期”“监管政策变化”只用于展示未来归因产品的交互方式，不代表这些股票曾出现相关事实，也不是已经估计或验证的下跌原因。

[进入网站](./index.html) · [方法与边界](./docs/METHOD.md) · [数据清单](./data/manifest.json)

## 数据

- 八只股票：`000001`、`000009`、`000011`、`000428`、`301092`、`600000`、`600367`、`688309`。
- 时间：2026 年 7 月的 23 个交易日，时间显示采用上海时区。
- 覆盖：184 个股票交易日、8,832 根五分钟 OHLCV K 线、184 条当日参考昨收记录。
- 原始快照已聚合为五分钟 K 线。本仓库不包含全部逐笔或逐秒原始数据。
- 仅保留演示所需的数据，不包含预警模型包、账号数据库、密码或云端连接配置。

## 交互与研究问题

预警系统询问“下跌是否可能发生”；本演示在观察到下跌之后展示“可以优先核查哪些解释”。目前候选原因和概率均人工预设，尚未构成实证归因或因果识别。

网站回放八只股票的价格变化，支持切换交易日、选股看图、控制播放和查看事件记录。监测覆盖八只股票；选中某只股票用于图表展示。默认案例为 2026 年 7 月 27 日 `000011`，在 13:40 观察到相对此前日内最高已收盘价格回撤约 6.60%。

提供两种观察口径：

1. **日内回撤**：当前已收盘 K 线价格，相对此前本交易日最高已收盘 K 线价格的变动。
2. **相对昨收**：当前已收盘 K 线价格，相对于数据中当日参考昨收价格的变动。

只有从阈值外进入“跌幅超过 5%”区间时才新增事件。同一段持续下跌不会每五分钟重复弹窗；恢复到阈值外后再次跌破会形成新事件。五分钟收盘价只能提供五分钟频率的检测，弹窗在回放检测到事件时立即出现，并不代表逐秒行情捕捉到了真实首次跌破时刻。

每次事件展示三条标注为“Demo”的候选原因。概率通过事件标识选择可复现的整数分配，不使用整十数，保持降序且合计 100%。三项数值之和为 100% 仅是界面约定，不是数据估计、真实后验概率或对所有可能原因的穷尽分解。

## 部署与复现

本项目由静态 HTML、CSS、JavaScript 和 JSON 构成，可部署到 GitHub Pages。页面、数据与计算均不依赖 AWS；EC2 停止后，GitHub Pages 版本仍可访问。公开版本无需账号登录，仓库中的价格数据与代码可公开下载。

本地预览：

```sh
python -m http.server 8080
```

然后在浏览器中打开 `http://localhost:8080/`。请通过 HTTP 访问，不直接以 `file://` 打开页面。

若已有获授权的八股票原始回放 JSON，可重新生成最小公开数据包：

```sh
python tools/prepare_data.py /path/to/authorized-replay.json
```

脚本使用 Python 标准库，校验股票数量、日期与 K 线顺序、OHLC 关系、非负成交量、数值有限性以及数据规模，输出 `data/replay.json` 和 `data/manifest.json`。清单包含 SHA-256 和两种口径的阈值跨越次数。它不会重新提取原始数据或运行模型训练。

## 后续接入

未来可以将虚构原因替换为有来源和发布时间的公告、新闻、政策与行业事件，并估计候选解释的排序或置信度。需要分别验证信息当时是否可获得、股票与事件之间的关联以及因果证据；文本匹配或模型给出较高分数本身不能证明因果关系。
