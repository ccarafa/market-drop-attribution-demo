# 官方日行情连接准备

> 2026-10-29 更新：凭证已取得并完成接入，当前路线、覆盖范围与更换方式见站内[数据接入](../sources.html)页；多路线连接检查使用工作流 `Data sources check`（`tools/check_data_sources.py`）。以下为最初的单接口连接准备说明，保留作为流程记录。

截至 2026-10-15，尚未以有效官方 API Token 完成业务响应验证，连接状态为**未接通**。已准备连接检查，不代表已取得最近一年数据、全市场权限或公开展示许可。现有网站继续使用已核验的 2026 年 7 月本地数据；本流程不修改该档案或 Demo。

**供应商回复后需要确认的内容**

| 项目 | 需要明确的答复 |
| --- | --- |
| 产品与鉴权 | 开通的是哪个 API 产品？提供的 Token 是否适用于 AI-Ready 的 `Astock_market_daily`？是否还需要 `app_id`、Skill 配置或其他 Header？旧版 API、数据字典网站登录与 Hermes 授权不可默认通用。 |
| 端点与字段 | 确认正式业务地址、当前接口定义、分页从 0 还是 1 开始、分页结束/总量判断，以及价格、收益、成交量单位和更新时间。 |
| 历史与证券范围 | 是否覆盖沪深京全部 A 股最近连续 12 个月？最早可得日期是什么？是否包括期间上市、退市、停牌证券，如何核查完整性？ |
| 费用与限额 | 按请求、返回行数还是积分计费？小额连接探测是否收费？确认价格单位、可用额度、速率/日限额及额度耗尽行为；本流程不购买套餐或提高额度。 |
| 网络限制 | 是否绑定 IP、需要白名单，是否允许 GitHub Actions 托管运行器访问？如要求固定出口，先确定兼容环境，不以重复请求尝试绕过限制。 |
| 展示与导出权限 | 是否允许公开网站展示价格与派生统计？是否允许浏览器下载事件证据、静态 JSON 和历史路径？明确缓存期限、署名要求及批量再分发边界。 |

请保留不含个人身份和凭证的授权范围说明。Token、密码、账户页面截图和完整响应不进入本文、Git 仓库、Issue、公开日志或聊天记录。

**保存 Token 并执行一次小范围检查**

1. 根据供应商确认的产品，核对[官方调用指南](https://d.datayes.com/guide)与[日行情接口定义](https://gw.datayes.com/aladdin_llm_mgmt/web/whitelist/api?nameEn=Astock_market_daily)。当前客户端仅支持已配置的日行情端点和 Bearer Token；若实际要求 `app_id` 或不同鉴权协议，先修正客户端，不能把其他产品密钥直接代入。
2. 在现有归因网站仓库的 **Settings → Secrets and variables → Actions → New repository secret** 中创建 `DATAYES_API_TOKEN`，值填写供应商发放的 API Token。保存为 Secret，不是普通 Variable、工作流输入或源码。字典网站的登录密码不能替代该 Token。[GitHub Secret 使用说明](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets)
3. 在仓库 **Actions → DataYes connection check → Run workflow** 中手动运行 `.github/workflows/datayes-connection.yml`。`trade_date` 填写供应商确认有权限的已结束交易日，格式为 `YYYY-MM-DD`；`ticker` 填写六位股票代码，默认 `000001`。此工作流只有手动触发，不设置定时任务，也不部署行情数据。
4. 工作流调用 `tools/check_datayes_connection.py`。探测上限固定为 **1 次业务请求、1 只股票、1 个日期、1 页、`pagesize=2`、最多接收 2 行**；不自动重试、不继续翻页、不扩大证券或日期范围。设置小上限不等于供应商保证免费，也不控制供应商的计费规则。
5. 只查看脱敏结果：检查状态、HTTP/业务错误类别、实际请求次数、返回行数和字段校验情况。不得输出 Token、请求头、供应商原始错误文本或实际价格记录。缺少 Secret 时应在发出业务请求前停止。

本地也可使用同一检查脚本；Token 只从已安全配置的 `DATAYES_API_TOKEN` 环境变量读取，不接受命令行密钥。下面的日期占位符须换成已确认的交易日。结果写入忽略目录，仅保留脱敏状态；GitHub 工作流产物也不包含财务数据行。

```text
python tools/check_datayes_connection.py --date YYYY-MM-DD --ticker 000001 --output .runtime/datayes-connection.json
```

**怎样解释检查结果**

- 有真实、非空、字段有效且匹配所选股票和日期的响应，才可记录“本次小范围连接检查通过”。HTTP 200、Secret 已保存、元数据可访问或工作流本身执行成功，都不能单独证明业务接口已接通。
- 空结果、鉴权失败、无权限、限额或限流、字段变化、超出边界和网络异常均保留为未验证/失败状态。根据明确错误修正配置后，再单独决定是否重跑；不能自动切换到模拟数据并显示成功。
- 单只股票单日检查不验证全市场、最近一年、所有字段或分页完整性，也不证明公开展示与导出已获授权。只有返回数量没有供应商总量依据时，不能标记完整数据库已下载。

连接检查通过并明确授权范围后，再进行可恢复的全年下载、分页与证券覆盖核查、价格/复权口径验证和官方数据版构建。官方日行情不提供的价差、盘口失衡保留为缺失；不补零、不生成原因概率，也不覆盖已有 July 档案。

本文是操作说明；实际连接状态以最近一次真实检查的脱敏结果为准。
