# 真实数据日度事件研究：计算口径与验证

本页是使用现有本地股票数据生成的**事后描述性研究**。同期收益差、成交量及盘口变化构成观测证据，不是原因概率、因果贡献或已经验证的预警能力。没有新增新闻、行业、公告或财报数据，也没有拟合长期 beta。

本次明确授权使用现有本地真实数据完成新页面，更新了原先仅限虚构归因演示的工作范围。原演示保留在 `demo.html`，其虚构原因与概率继续标记为 Demo；本研究的数据、方法和结果与其分开。

## 事件规则和价格口径

对来源的 `daily_return_proxy` 计算：

```text
日收益代理 = last_price_proxy / prev_close - 1
事件 = 有限日收益代理 < -0.05 - 1e-12
```

价格是**未复权的最后有效快照价格**，参考价来自来源中的 `prev_close`，不保证是独立核验的官方收盘价或相邻日同一价格基准。本次将 119,492 个有效收益逐一用价格重建，最大绝对误差为 0。

恰好 -5% 的数值及其浮点表示不触发事件。每个股票日期只有一条记录，重复键导致构建失败。13,246 是全部日期按严格容差重新计算的结果；不能使用旧浮点比较汇总中的 13,255。它也不同于保留 Demo 的五分钟回撤穿越事件，两种时间频率与定义不能混比。

原始事件全部保留，包括触发价格基准差异提示的事件。筛选用于比较样本和敏感性查看，不删除原始事件记录，也不将其重新解释为已验证的经济冲击。

## 同期样本比较

在每个日期，对目标股票从比较池中移除后计算收益中位数：

```text
相对差值 = 本股日收益代理 - 同期其他有效股票收益中位数
跌幅广度 = 同期其他有效股票中严格跌超 5% 的数量 / 同期其他有效股票数量
```

中位数是等权样本统计，不是官方指数，不采用市值权重。显示的 `baseline_n` 是移除目标后的实际分母。目标本来不符合筛选时，不从比较池重复减去一条。相同收益值按唯一股票日期键定位，确保只移除该股票本身；没有可比较股票时结果为 `null`。

每条事件同时提供两个版本：

- `sample_median_return`、`excess_return`、`down5_breadth` 和 `baseline_n` 使用筛选后比较池。
- `raw_sample_median_return`、`raw_excess_return`、`raw_down5_breadth` 和 `raw_baseline_n` 使用有限收益及正价格的全部记录。

首页按日期汇总的市场卡片使用该日整个比较池，**不**移除某一目标；它与个股事件卡的中位数或广度可以有细微差异。任何相对差值都只是算术比较，不是市场因素对个股的因果贡献。

## 筛选与参考价检查

每只股票将本日参考前收盘价与**前一条可观察股票日的末价**比较：

```text
reference_gap = 本日 prev_close / 前一观察日 last_price_proxy - 1
```

在价格可比较的 114,291 对记录中，有 719 对超过相对误差 `1e-8` 的连续性检查，其中 353 对绝对差异严格超过 1%（另加 `1e-12` 边界容差）。这些差异可能涉及公司行动、上市或来源定义，不能仅凭该检查判为错误或原因。

筛选后的比较池要求有限收益和正价格，并排除：

1. 已知 `abs(reference_gap) > 0.01 + 1e-12`。
2. `abs(return) > 0.50 + 1e-12`。

实际排除 518 个股票日，包括 160 个无效收益/价格、353 个参考基准差异和 5 个绝对收益超过 50% 的记录。13,246 个原始事件中有 19 个带参考差异提示，因此筛选后保留 13,227 个事件。这两个数字均公开，避免筛选过程掩盖敏感性。

**缺少历史核验的记录没有被认定为连续。** 共 5,361 个股票日没有可比较的前一观察日末价，包括每只股票的首条观察及此前价格无效等情况；其中有 207 个原始事件。它们保留在比较池中，但明确标记 `reference_history_missing`。因此“筛选后”不等于价格连续性已获得认证。

价差和盘口统计缺失不会自动删除一个价格有效的收益观察，相关指标独立标记并显示为空，避免将不同问题混成一种剔除规则。

## 历史量价指标

为每只股票按日期排序，只取**当前日期之前五条可观察记录**，不包含当日。每项指标要求该窗口中有五个有效值，否则基准、量比或差值显示为空，并返回 0 至 5 的实际有效数量。

| 指标 | 当前值与历史基准 | 有效值要求 |
| --- | --- | --- |
| 成交量比 | 当日最终累计成交量 / 前 5 个观察日成交量中位数 | 成交量有限且严格为正 |
| 价差比 | 当日平均价差 / 前 5 个观察日平均价差中位数 | 价差有限且非负；基准还须严格为正才能相除 |
| 盘口不平衡变化 | 当日平均绝对盘口不平衡 - 前 5 个观察日中位数 | 数值有限且在 0 至 1 范围内，容差 `1e-12` |

窗口不会跳过一个无效值后再向更早日期补足，也不会用未来数据或零填充。缺少整天记录时使用此前可观察的股票日，并不声称它们必然是连续交易日。成交量保持来源的股数约定；相对倍数使用同一来源和单位。

盘口指标为**绝对**不平衡，不能用于区分买压和卖压。量比、价差和盘口变化只描述同时出现的交易特征，不命名为抛售原因。

## 时间与展示约束

所有指标均为完整日度汇总。每个日期的展示时间取以下两者中更晚者：

- 当日 16:00，按 `Asia/Shanghai` 展示约定。
- 该日全部纳入记录中最后一个来源快照时间。

这样，同日其他股票的完整统计也已具备所需来源信息。实际输入每个日期均可按 16:00 展示。原始字典未独立确认时区，`Asia/Shanghai` 是明确记录的历史展示约定，不夸大来源时间规范的确定性。

逐股历史图在所选事件日期截断，不提前显示后续日期。图表应将首日及早期历史不足作为缺失，而不是用未来日期补齐。此页面不将全天成交量、末价或全日价差作为当天盘中已经知道的信息；它不是交易信号回测。

## 文件与数值精度

- `data/study.json`：完整事件证据、日期汇总、元数据及字段和提示字典；使用自描述 `columns` 和紧凑行数组。事件值及所有计算均保留 Python 浮点精度。
- `data/series/0.json`、`3.json`、`6.json`：按股票代码首位分片的历史图表数据，各自有独立 `columns`。股票代码取自 `symbols` 字典键，日期可用时间取自 `market_by_date`。
- `.runtime/study-audit.json`：本地审计，包含输入与构建程序哈希、输出哈希、覆盖验证及检查样例；不公开发布。

为控制移动端加载量，历史图只保存日期、末价、收益、成交量、价差、绝对盘口不平衡、筛选状态和提示。图表投影分别将价格保留 6 位小数、收益 8 位、成交量 4 位、价差 6 位、盘口不平衡 8 位。**图表舍入值不参与事件分类、历史基准、汇总或导出证据计算。** 原始事件详情和导出仍保留完整精度。

## 复现与验证

本地构建程序为 `tools/build_real_study.py`。读取原始 Parquet 需要 `pyarrow`；计算本身与单元测试使用 Python 标准库。若输入不在已知本地相对位置，可运行：

```text
python tools/build_real_study.py --source <local-daily-aggregate.parquet>
python -m unittest discover -s tests -p test_real_study.py -v
```

构建校验股票/日期覆盖、唯一键、严格事件数量、价格重建和 JSON 有限数值。合成测试验证严格 -5% 边界、缺失与无效值、留一中位数和重复值、历史窗口先移位、未来数据扰动不影响既有指标、筛选后仍保留原始事件，以及晚到快照的最早展示时间。

提交数据测试逐条检查 13,246 个事件的唯一键、阈值和价格重建，并确认 119,652 条历史投影覆盖所有事件、筛选计数及日期汇总一致。测试不依赖私有输入文件，便于公开仓库持续验证。

研究范围只有一个月，股票间和相邻日期的事件并非独立。结果不能外推为可靠的预警表现、原因概率或已经识别的因果机制。
