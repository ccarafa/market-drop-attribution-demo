# 事件归因方法说明

本页说明 `attribution.html` 所展示的原因分解与概率如何得出。所有数字均来自 2026 年 7 月样本内的统计，不是因果证明。

## 1. 数据来源

| 来源 | 内容 | 使用方式 |
| --- | --- | --- |
| 本地日汇总（`daily_features`） | 5,210 个股票代码、23 个交易日、119,652 个股票日的末次有效价格、参考前收盘、成交量、平均价差与盘口失衡 | 事件定义、市场与行业中位数、成交盘口指标；口径筛查沿用 `docs/REAL_DATA_METHOD.md` |
| 供应商公告元数据 | 2026-06-22 至 2026-08-03 全市场公告的标题、分类、股票代码、申万一级行业、发布时间戳 | 本公司公告、同行业公告、行业归属；只存元数据，不下载正文 |
| 财经公众号文章元数据 | 同期财经类文章的标题、来源、发布时间、关联股票代码、原文链接 | 本股文章、行业报道、监管与宏观背景 |
| 供应商日资金流向 | 2026-06-22 至 2026-07-31 全市场每日的小、中、大、超大单净流入与成交额 | 主力、超大单与中小单的资金流向特征与展示 |
| 快照盘口汇总（可选） | 由项目自有的逐笔快照计算的五分钟 bar 与股票日汇总 | 主动买卖、大额成交、涨跌停触及等成交盘口证据 |

## 2. 事件定义

日收益 = 当日末价 ÷ 参考前收盘价 − 1。严格超过 2%、3%、5%（边界容差 10⁻¹²）分别记为三个阈值层级的事件，涨跌分别统计。页面按阈值和方向筛选，概率校准也按阈值和方向分别进行。

## 3. 收益分解

```
个股收益 = 市场中位数 + （行业中位数 − 市场中位数） + 个股特有部分
```

- 市场中位数：同日通过口径筛查、剔除本股的样本收益中位数。
- 行业中位数：同一申万一级行业（取自公告元数据中的行业标签）、剔除本股的筛查后收益中位数；同行不足 8 只时不计算行业层。
- 份额：只在与个股收益同向时计入，按幅度占比折算并截断在 0 到 1 之间；两者之和超过 1 时按比例缩放。其余为个股特有部分。

## 4. 证据窗口

公告与文章按发布时间（上海时间）落入以下窗口：

| 窗口 | 范围 | 作用 |
| --- | --- | --- |
| 前一交易日收盘后至当日开盘前 | (前一交易日 15:00, 当日 09:30] | 当日异动前已知的信息 |
| 当日交易时段 | (09:30, 15:00] | 盘中出现的信息 |
| 当日收盘后 | (15:00, 下一交易日 09:30] | 只作事后解释，不计入原因 |
| 此前 2 至 5 个交易日 | (第 5 个前交易日 15:00, 前一交易日 15:00] | 近期已披露的信息 |

样本内 99% 以上的公告在 15:00 之后发布，因此公告类原因主要通过第一个窗口起作用。交易日历取样本日期并补入 2026-06-22 至 06-30 的工作日与 2026-08-03。

## 5. 证据特征

- 本公司公告：按公告分类映射为业绩与财务披露、股东减持、股东增持、股份回购、限售股解禁、股权质押或冻结、风险警示或退市、交易异常波动、停复牌、澄清、资产重组或并购、再融资、高管变动、诉讼或监管问询、重大合同、政策影响、分红等家族；标题关键词决定偏正面或偏负面。股东大会、董事会、中介机构等日常经营类公告不作为原因。
- 同行业公告：同一行业中不少于行业样本一成且至少 3 家公司在同一窗口披露同向重要公告。
- 财经文章：关联股票代码包含本股的文章；标题含行业关键词的文章（2 篇以上）；标题同时含监管关键词与行业关键词的文章，并按标题情绪分为偏负面、偏正面或中性三种特征。样本内多数文章特征的似然比低于 1.5，因此通常只作为证据列出而不计入概率。
- 成交盘口：成交量达到前 5 日中位数 2 倍或 4 倍、平均价差达到 1.5 倍、盘口绝对失衡上升 0.1 以上；有快照汇总时增加开盘跳空、主动买卖占比、大额成交占比、触及涨跌停。
- 资金流向：供应商按单笔成交金额把成交拆为小单、中单、大单、超大单，主力 = 大单 + 超大单。特征为主力净流出或净流入达到当日成交额一成以上、超大单净流出或净流入达到半成以上、以及"散户接盘"（主力净流出同时中小单净流入达到半成以上）。这些份额描述成交单的大小分布，不识别交易者身份；事件页面同时列出各档净流入金额与占比。

## 6. 概率

对每种证据特征 X，在全部筛查后股票日中计算：

```
LR = P(X | 异动日) ÷ P(X | 非异动日)        （加 0.5 平滑）
权重 = max(0, 1 − 1 / LR) × min(1, 观察数 ÷ 30)
```

`1 − 1/LR` 是流行病学中“暴露者归因分数”的形式：在出现该证据的异动日中，超出基准发生率的份额。观察数不足 30 时线性收缩。

事件的个股特有部分按与方向一致的现有证据权重成比例分配；与方向相反的证据列为“反向信息”，收盘后公告列为“事后披露”，均不计入。成交盘口类证据合并为一个候选并始终保留 0.02 的最低权重，因此没有公开信息的事件仍会给出成交与盘口原因，并在页面上说明。

页面上每个原因都附带：出现该证据的股票日中当日异动的比例、无该证据时的基准发生率、似然比和异动日出现次数。

## 7. 边界

- 校准在同一样本内完成，没有样本外验证；概率表达的是关联强度，不是因果。
- 公告分类与新闻关键词可能漏判或误判；没有公告的股票没有行业归属。
- 成交盘口指标由约三秒一条的快照推断，tick 规则与笔均额只是主动买卖和大额成交的代理，不能识别交易者身份。
- 日度观察在当日 16:00 后完整；本页不声称盘中可预测。
- 公告与文章只展示标题、时间与来源链接；原始数据与凭证不进入本站。

复现：`python tools/build_attribution.py --daily <日汇总 Parquet> --evidence <证据目录> [--moneyflow <资金流向目录>] [--intraday <快照汇总 Parquet>]`，输出 `data/attribution/index.json` 与 `data/attribution/events/*.json`。单元测试：`python -m unittest tests.test_attribution`。
