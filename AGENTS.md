# Project rules

Use neutral aliases only in records. Do not write personal names, identity mappings, credential contents or identity-bearing local paths.

This is a separately authorized public historical attribution DEMO. Market prices come from the existing eight-stock replay pack. All explanations and displayed probabilities are invented examples. Keep this distinction visible in each popup, reason list and export. Never describe example probabilities as calibrated estimates, verified news or causal findings. Do not fetch AWS or restart research work.

Only finished five-minute close observations trigger events. Default basis is current close relative to the highest previously completed close of the same day; alternate basis is reference previous close. Strict decline greater than 5%, with 1e-12 tolerance. Emit when crossing the threshold, not on every bar that remains below it. A recovery permits a new crossing. The next-event navigation is retrospective case selection, not prediction.

Use relative static paths for GitHub Pages. Do not add server authentication to a public static page. Never commit .runtime/, accounts, keys, raw archives or unrelated market data.

Run `npm test` and `python tools/check_browser.py` for material engine/UI changes; pass the actual HTTPS URL to the latter to verify publication. Tools may use the existing local Python environment with websocket-client. Publishing is through authenticated gh CLI and an explicit file allowlist.
